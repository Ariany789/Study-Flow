# Contribuindo

1. Crie uma branch com prefixo `feature/`, `fix/`, `docs/` ou `refactor/`.
2. Mantenha as mudanças pequenas e alinhadas à arquitetura existente.
3. Atualize testes e documentação junto com a funcionalidade.
4. Execute `python -m pytest` no backend e `npm run build` no frontend.
5. Use commits claros, como `feat: add study session endpoint`.
